📊 Mobile Sales Dashboard (Power BI)
📌 Project Overview :

This project focuses on analyzing mobile sales data using Power BI. The dashboard provides clear insights into sales performance, customer behavior, and trends over time. It is designed to simulate a real-world business scenario and demonstrate data analysis and visualization skills.

📂 Dataset:
Source: Sample Mobile Sales Dataset
Format: Excel (.xlsx)
Data includes:
-Product details
-Sales amount
-Order dates
-Categories and regions

⚙️ Tools & Technologies Used
-Power BI
-Microsoft Excel
-DAX (Data Analysis Expressions)

📈 Key Features
-Data cleaning and transformation
-Custom calendar table using DAX
-Data modeling with relationships
-Time intelligence calculations:
-MTD (Month-to-Date)
-QTD (Quarter-to-Date)
-YTD (Year-to-Date)
-Same Period Last Year comparison
-Interactive dashboard with slicers, edit interactions, and page navigation between report pages.
